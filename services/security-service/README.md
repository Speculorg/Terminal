# Speculorg.Terminal.Security.Service

This directory contains the source code for Speculorg.Terminal.Security.Service, a Django microservice responsible for managing the security aspects of the Speculorg.Terminal project.

## Overview
The Security Service is responsible for:
- Authentication and authorization
- Identity and access management
- Security policy enforcement
- Audit logging and monitoring
- Security incident response
- Compliance management

## Dependencies
- Django 5.1.8
- Python 3.13.1
- Keycloak integration
- Additional security-related dependencies will be added as needed
