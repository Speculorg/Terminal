
# Дорожная карта Speculorg.Terminal (MVP)

Это стратегический план развития MVP торговой и аналитической платформы.

Ниже представлены ключевые фазы этого плана:

---

## Фаза 1: Разработка MVP

- **Исследование и разработка:**
    - Выработка требований к проекту. (*завершено*)
    - Выбор архитектуры и технологического стека. (*завершено*)
    - Разработка технической документации. (*завершено*)
    - Подготовка документации к публикации на `docs.specul.org`. (*в процессе*)

- **Инфраструктура:**
    - Развёртывание ключевых компонентов:
        - **RabbitMQ**: для обработки очередей сообщений между сервисами.
        - **Redis**: для кэширования данных и ускорения операций.
        - **TimescaleDB**: для анализа временных рядов и хранения исторических данных.
        - **Keycloak**: для централизованного управления пользователями и авторизацией (OAuth2).
        - **Traefik**: для балансировки нагрузки и маршрутизации API-запросов.
        - **HashiCorp Consul**: Сервисное обнаружение, управление конфигурациями.
        - **HashiCorp Vault**: для безопасного хранения секретов и токенов.
        - **Prometheus** и **Grafana**: мониторинг метрик и визуализация.
        - **ELK Stack** (Elasticsearch, Logstash, Kibana): централизованное логирование.
    - Настройка CI/CD:
        - **GitHub Actions**: автоматизация сборки и развёртывания.
        - **Ansible** и **Terraform**: управление инфраструктурой и конфигурацией.

- **Базовая функциональность:**
    - Управление системой:
        - Управление пользователями и правами.
        - Управление инфраструктурой.
        - Управление интеграциями.
        - Управление локализацией.
        - Управление конфигурацией.
    - Интеграция с агрегатором данных **CoinMarketCap**:
        - Получение информации об активах.
        - Получение глобальных рыночных метрик.
    - Управление библиотекой активов и категориями.
    - Управление избранными активами.
    - Интеграция спот-рынков бирж **MEXC** и **Kucoin**:
        - Получение рыночных данных (тикеры, стаканы, лента сделок).
        - Получение торговых данных (баланс, открытые ордера, история сделок).
        - Поддержка спотовой торговли.
        - Базовая функциональность для спотовой торговли (лимитные и рыночные заявки).
    - Хранение данных:
        - Исторические рыночные данные (OHLCV).
        - Исторические торговые данные.
        - Логи операций для анализа и аудита.
    - Исследование и разработка системы модулей и плагинов для добавления новых функций.
    - Исследование и разработка системы кэширования данных.
    - Исследование и разработка системы для создания и настройки пользовательских стратегий.

- **UI/UX:**
    - Базовые страницы для Пользователя.
    - Базовые страницы для Администратора.

- **Безопасность:**
    - Реализация многоуровневой аутентификации (OAuth2, OpenID Connect).
    - Шифрование данных в движении (TLS) и покое (HashiCorp Vault).
    - Настройка RBAC (Role-Based Access Control) для разграничения прав доступа.

- **Тестирование и мониторинг:**
    - Покрытие ключевых функций юнит- и интеграционными тестами.
    - Настройка мониторинга ошибок через **Sentry**.
    - Логирование взаимодействий через **ELK Stack**.

## Фаза 2: Расширение функциональности

- **Исследование и разработка:**
    - Уточнение требований.
    - Улучшение архитектуры.
    - Улучшение и дополнение технической документации.

- **Расширение рынков, активов и источников данных:**
    - Поддержка новых типов рынков (фьючерсы, маржинальная торговля, earn).
    - Поддержка новых типов инструментов (акции, облигации).
    - Расширение интеграций (CoinGecko, Finam).
    - Интеграция дополнительных источников данных, включая новости и соцсети.
    - Расширенные технические индикаторы, скринеры, фундаментальный анализ.
    - Арбитраж между биржами.

- **Дополнительные модули:**
    - Внедрение системы модулей и плагинов.
    - Управление портфелем пользователей.
    - Внедрение механизмов управления рисками.
    - Инструменты технического анализа:
        - Расширенные индикаторы (SMA, EMA, RSI, MACD, Bollinger Bands).
        - Построение графиков.
    - Фундаментальный анализ:
        - Интеграция с новостными сервисами (NewsAPI).
        - Анализ социальных настроений (Twitter, Reddit).
    - Визуальный конструктор, для создания и настройки пользовательских стратегий.

- **UI/UX:**
    - Улучшение страниц для Пользователя.
    - Улучшение страниц для Администратора.

- **Автоматизация:**
    - Инструменты для бэктестинга и симуляции на исторических данных.
    - Оптимизация стратегий с помощью машинного обучения.
    - Автоматическая генерация предсказаний и торговых рекомендаций.
    - Автоматическая оптимизация портфеля.
    - Автоматическое выявление аномалий и паттернов.
