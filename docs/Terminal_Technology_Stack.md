
# Стек технологий Speculorg.Terminal

Система **Speculorg.Terminal** построена на современных технологиях и инструментах, обеспечивающих высокую производительность, гибкость и масштабируемость.

Выбор технологий продиктован необходимостью обработки больших объёмов данных в реальном времени, интеграции с внешними сервисами и обеспечения надёжной работы системы.

Ниже представлены основные компоненты технологического стека Speculorg.Terminal:

---

## Язык программирования

- **Python 3.x**: Основной язык разработки, используемый для реализации микросервисов, бизнес-логики, интеграций и аналитических инструментов.

---

## Фреймворки и библиотеки

- **Django**: Фреймворк для реализации микросервисов контекстов (ContextMicroservice), обеспечивающий управление бизнес-логикой и данными.
- **FastAPI**: Фреймворк для реализации микросервисов контекстов (ContextMicroservice) и адаптеров внешних сервисов (ExternalServiceAdapter).
- **Celery**: Библиотека для реализации асинхронных задач и распределенной обработки.
- **Keycloak**: Система управления идентификацией и доступом (IAM) для аутентификации и авторизации пользователей.

---

## Хранение данных

- **PostgreSQL**: Реляционная база данных для хранения основной информации.
- **TimescaleDB**: База данных для хранения временных рядов.
- **Redis**: Система кэширования данных в памяти и брокер сообщений для Celery.
- **Elasticsearch**: Поисковый движок и хранилище для логирования и аналитики.

---

## Очереди сообщений и брокеры

- **RabbitMQ**: Брокер сообщений для асинхронного взаимодействия между микросервисами.
- **Kafka** (опционально): Для обработки больших потоков данных и событий в реальном времени.

---

## Инфраструктура и развёртывание

- **Docker**: Платформа для контейнеризации приложений.
- **Docker Compose**: Система оркестрации контейнеров для управления развертыванием и масштабированием.
- **Traefik**: Маршрутизатор и балансировщик нагрузки для управления входящими запросами.
- **HashiCorp Consul**: Инструмент для сервисного обнаружения и управления конфигурациями.
- **HashiCorp Vault**: Система для безопасного хранения и управления секретами.

---

## Мониторинг и логирование

- **Prometheus**: Система мониторинга и оповещения.
- **Grafana**: Платформа для визуализации метрик и создания дашбордов.
- **ELK Stack**: инструменты для сбора, обработки и визуализации логов (Elasticsearch, Logstash, Kibana).
- **Sentry**: Инструмент для отслеживания и уведомления о критических ошибках.
- **OpenTelemetry**: Инструменты для трассировки и мониторинга производительности приложений.

---

## Инструменты разработки и тестирования

- **Git**: Система контроля версий.
- **GitLab CI/CD**: Инструменты для непрерывной интеграции и доставки.
- **PyTest**: Фреймворк для написания и запуска тестов.
- **Swagger/OpenAPI**: Инструменты для документирования и тестирования API.

---
